# 三分钟演示讲稿

## 开场 · 20秒

“我是北邮学生。这个项目来自一个常见问题：作业、实验报告和截止时间散落在课程群里，通知一改，计划又要重排。邮课雷达把通知变成有依据、可确认、能排期的任务。”

## 现场导入 · 50秒

打开导入页，选人工构造通知图片，或点击“填入演示通知”后提取。

“这里是真实调用大模型。任务不会直接进入清单，我先核验截止时间和原文，再确认预估工时。图片识别的引用会提示对照原图。”

若模型连接失败，展示可重试提示，修复网络后重新调用；不要把缓存当新结果。

## 变更与排期 · 60秒

生成计划，再导入提前截止通知，核对前后变化后确认。回到计划页重新安排。

“模型理解通知，确定性程序做排期。它不会偷偷覆盖原任务，也不会安排到课程时间里。每次修改都能回看历史。”

增加一个与空闲时间重叠的不可用时段，展示未安排工作量。

## 边界与评测 · 50秒

导入缺少截止日期的通知，展示待确认。打开真实评测，解释12个案例及已有报告；若现场时间允许再运行一次，通常需要一分钟左右，具体取决于模型服务。

“日期不明时，它选择询问；容量不足时，它告诉你还差多少时间。我们用独立人工标注来测效果，字段匹配、漏项和失败都公开。小样本的高分不代表所有通知都能正确理解。”

## 现场准备

- 后端已启动；模拟器到电脑端口转接已建立；健康检查显示模型已配置。
- 模拟器安装的是最新HAP，应用设置的后端地址正确。
- 截图/PDF已导入模拟器；若媒体库不可用，先使用文字演示闭环，再说明文件选择器状态。
- 示例材料中的日期在演示当天之后；应用内示例会自动使用未来日期。
- 模型密钥保留电脑本地，不展示 `.env`，不写入手机或提交仓库。
- 若评委选用自己的材料，先说明将发送给当前配置的大模型服务，避免无意上传个人隐私。
