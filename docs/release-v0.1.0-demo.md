# 邮课雷达 v0.1.0-demo

面向学生的 HarmonyOS 原生 AI 课业管家：把课程通知整理成带原文依据、能追踪变更、可自动排期的任务。

## 本次功能

- 文字、通知截图、文字型PDF解析与原文回看。
- 核验后确认任务，识别截止时间变更，保留历史版本。
- 七天学习计划：30分钟粒度，避开课程与不可用时间。
- 离线缓存与12组真实模型评测入口。

## 安装与运行

附件 `entry-default-unsigned.hap` 为未签名模拟器调试包。已在 DevEco Studio 26.0.0.865、API26 / HarmonyOS 7.0.0.107(SP8) 手机模拟器安装运行。

1. 下载源码和HAP，按README安装Python依赖并配置自己的模型服务。
2. 启动本机后端，运行 `scripts/connect-emulator.ps1` 建立端口连接。
3. 使用 `hdc install -r` 安装HAP；应用后端地址设为 `http://127.0.0.1:8000`。

完整步骤见仓库 README。附件 `SHA256SUMS.txt` 用于校验下载包。
